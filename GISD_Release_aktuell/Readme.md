Mit dem aktuellen GISD release 2026 v0.1 wurde die Datenbereitstellung im Repositorium geändert. 
Die Daten werden im ".tsv"- und ".xlsx"-Format bereitgestellt. 
Die Datei [00_GISD_Bund.xlsx](https://github.com/robert-koch-institut/German_Index_of_Socioeconomic_Deprivation_GISD/blob/main/GISD_Release_aktuell/00_GISD_Bund.xlsx) enthält die GISD-Scores für die regionalen Einheiten bezogen auf das gesamte Bundesgebiet. Die jeweilige regionale Ebene kann über die Mappen (bzw. Sheets) der .xlsx-Datei gewählt werden. 
Die Datei [GISD_Bund.tsv](https://github.com/robert-koch-institut/German_Index_of_Socioeconomic_Deprivation_GISD/blob/main/GISD_Bund.tsv) ersetzt die Dateien im ".csv"-Format. Sie befindet sich nun im [Root-Ordner](https://github.com/robert-koch-institut/German_Index_of_Socioeconomic_Deprivation_GISD/). Sie enthält ebenfalls die GISD-Scores für alle regionalen Einheiten bezogen auf das gesamte Bundesgebiet. Die Variable region_type gibt die regionale Ebene wieder und muss als Filter verwendet werden, um auf die gewünschte Ebene einzuschränken.
